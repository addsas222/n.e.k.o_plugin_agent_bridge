# DESIGN.md — agent_bridge 控制台

> 格式沿用 Stitch DESIGN.md（VoltAgent/awesome-design-md §1–§9）。
> 设计取向取自 pbakaus/impeccable 的 `distill` / `layout` / `typeset` / `harden`
> 四条命令所约束的方向：**删掉页面不需要的东西、按节奏排版、把边界情况做实**。
> 品牌调性取自 taste-skill 的做法：界面是"仪器"，不是"作品集"。

## 1. Visual Theme & Atmosphere

工业仪表盘。默认密度高、装饰为零、对比明确。用户打开它的唯一目的是
**三秒内知道哪些 Agent 能用、并对其中一个派活**。

禁止：渐变、玻璃拟态、投影、圆角、插画、emoji 图标、引导气泡、欢迎弹窗。
允许：1px 实线、单色块、等宽字体、状态色（仅用于表达状态）。

## 2. Color Palette & Roles

| 语义 | 值 | 用途 |
|---|---|---|
| `--paper` | `#f2f2ef` | 页面底（暖灰，降低纯白刺眼） |
| `--surface` | `#ffffff` | 面板 / 表格行 |
| `--ink` | `#111112` | 主文字、选中行底色（反白） |
| `--ink-2` | `#5a5a5e` | 次级文字（标签、列头） |
| `--line` | `#d3d3ce` | 所有分隔线、输入框描边 |
| `--line-2` | `#b9b9b3` | 悬停态描边 |
| `--ok` | `#1a7f37` | 就绪 |
| `--warn` | `#8a5a00` | 未登录 / 待办（**不用黄色填充，只用于文字与 3px 方块**） |
| `--bad` | `#b42318` | 失败 |
| `--idle` | `#6b6b70` | 缺失 / 未安装 |

状态色**只出现在 6px 方块与文字上**，不做整行染色 —— 整行染色会让 12 行都在喊。

## 3. Typography Rules

| 角色 | 字体 | 字号 / 行高 | 用法 |
|---|---|---|---|
| 数据 | `ui-monospace, "Cascadia Mono", Consolas, monospace` | 12 / 18 | id、命令、输出、数字 |
| 标签 | `system-ui, "Segoe UI", sans-serif` | 12 / 16 | 列头、按钮 |
| 标题 | 同上 | 13 / 18，字重 600，字距 0.02em，**全大写** | 区段标题 |
| 大数 | 等宽 | 22 / 26 | 顶部计数 |

数字一律 `font-variant-numeric: tabular-nums`。正文最小 12px，不再小。

## 4. Component Stylings

**状态码（chip）**：`[■] 文本` —— 6px 实心方块 + 12px 文字，无边框无圆角无底色。
`OK` / `需登录` / `失败` / `缺失` / `已禁用` 五种。

**表格**：行高 30px，行间 1px 分隔线；选中行整体反白（`--ink` 底 + `--surface` 字）；
悬停仅换描边色，不换底色。列头 28px、全大写、字距 0.04em、吸顶。

**按钮**：高 28px，1px 描边，`--surface` 底、`--ink` 字；主按钮反白（`--ink` 底）。
悬停把描边换成 `--ink`；按下位移 1px（`transform: translateY(1px)`），无阴影。

**输入框**：高 28px，1px `--line`，聚焦时换成 `--ink` 2px 外框（`outline-offset: -1px`）。
等宽字体。

**输出区**：反白面板（`--ink` 底、`#e8e8e4` 字），等宽，`white-space: pre-wrap`，
最大高 40vh 内滚 —— 长输出不能把页面顶开。

## 5. Layout Principles

- 间距只有 4 个值：4 / 8 / 12 / 24。不出现 5、7、10、15。
- 顶栏 44px 固定；主体两栏 `1fr / 380px`，间距 1px（靠描边分隔，不靠留白）；
  底部审计条 132px。
- 左栏是**唯一的主界面**：表格就是导航，点行 = 选中，不需要下拉框选 Agent。
- 右栏随选中项变化；未选中时显示空态（一句话 + 快捷键提示），不显示禁用态表单。
- 1280px 以下右栏降到 320px；960px 以下堆叠（表格在上，派发在下）。

## 6. Depth & Elevation

**没有 elevation。** 层次只靠三样东西表达：1px 描边、底色深浅（paper/surface/ink）、
字号字重。任何需要"浮起来"的地方，改用一个反白块，不加阴影。

## 7. Do's and Don'ts

Do
- 把状态放左列，把动作放右列 —— 眼睛先扫状态，再决定动作。
- 每个数字都用等宽 + 右对齐。
- 空态给一句可执行的话（"选中一行，按 Enter 派发"）。
- 长文本截断 + `title` 全量。

Don't
- 不用圆角（全局 `border-radius: 0`，包括 chip、输入框、按钮）。
- 不用图标字体/emoji 当状态；用方块 + 文字。
- 不做卡片网格 —— 12 个 Agent 用表格是 3 秒，用卡片是 30 秒。
- 不在表格里放多行说明；说明进右侧详情。
- 不用 `transition` 超过 120ms；不做淡入动画。

## 8. Responsive Behavior

| 断点 | 行为 |
|---|---|
| ≥1280 | 两栏，右栏 380 |
| 960–1280 | 两栏，右栏 320；隐藏"命令"列 |
| <960 | 单栏堆叠；表格保留 id/状态/版本三列；右栏吸底 |

触控目标最小 28px（行 30px 已满足）；键盘 `j/k` 移动、`Enter` 派发、`/` 聚焦、
`r` 刷新、`e` 启停 —— 全部有可见焦点框。

## 9. Agent Prompt Guide

给后续改这个页面的 Agent：

```
保持：直角（border-radius:0）、1px 描边、等宽数据、状态色只用于方块与文字、
      表格优先、快捷键 j/k/Enter/r/e、空态给可执行提示。
禁止：渐变、阴影、圆角、卡片网格、图标字体、动画超过 120ms。
新增一列前先问：它能让用户更快下决定吗？不能就不加。
```
