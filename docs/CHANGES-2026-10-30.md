1. 抽出内联脚本 `node --check` → **语法通过**（排除整段 JS 挂掉）；

## 13. 第七轮：探测改为服务端预热

现象：面板打开后版本列全是「↻ 探测」，用户认为探测没启动。

排查：
1. 抽出内联 JS `node --check` → 语法通过；
2. 审计 JS 引用的元素 id → **无缺失**，绑定路径完整；
3. 直接打接口：`/api/version` 冷 0.2s、缓存 0.1s —— **接口本身很快**；
4. 无头 Edge 想拿执行后 DOM → 这台机器 headless 起不来（about:blank 都空），换思路。

结论：把"探测"放在浏览器里做本身就是脆的 —— 页面必须先渲染一排按钮、再靠前端并发去补，
任何一步慢/失败，用户看到的就是"一排没反应的按钮"。

改法（搬服务端）：

| 改动 | 说明 |
|---|---|
| `_warm_versions()` | 启动时后台并发 3 把已装 Agent 探一遍写进缓存 |
| `/api/agents` 带 `version` | 首屏直接有版本，不再依赖前端探测 |
| `_VERSION_CACHE` + `VERSION_TTL=600s` | 重复请求 0.1s；`refresh=1` 强制绕过（顺序写错过一次：缓存先命中，点探测等于没点） |
| 占位符不缓存 | `<超时>` / `<无输出>` 不是版本，返回空 + `note`，让按钮留着可重试 |
| 前端去掉 autoProbe | 只保留"刷新/补探"语义；探测中显示`探测中`，失败还回按钮 |
| 面板自己写审计 | 以前只读别人的 `dispatch.jsonl`，所以"最近派发"是旧数据；现在每条带 `ts` + `source:"webui"` |

实测：`/api/agents` 首屏 **11/13 带版本**（dsh 未装、qwenpaw 探不到）；
`refresh=1` 真跑 4.0s 并回填；缓存命中 0.1s。

## 16. 第十轮：修列错位 + 列宽可调

**Bug**：窄屏下「别名」列显示的是命令、「命令」列显示的是版本。

**修法**：表头与单元格**由同一份 `visibleCols()` 生成**。

| 改动 | 说明 |

| 列宽拖拽 | 每个 `th` 右缘 7px 手柄，拖动改 `<col>` 宽度，最小宽度按列定义；**双击复位**；存 localStorage `ab-cols` |

## 19. 第十三轮：表格没有滚动条 / 目录列不可读

**现象**：HARNESS 页 69 行把容器撑破，看不到滚动条，底部日志条直接压住表格。

**根因**：`main` 是 grid，grid 子项的 `min-height` 默认是 `auto` ——
`section.list` 没写 `min-height:0`，于是它不会收缩，`flex:1; overflow:auto` 的
`.scroll` 被内容撑到自然高度，滚动条永远不出现（内容只是被裁掉）。

修法：

| 改动 | 说明 |
|---|---|
| `section.list` / `aside` 加 `min-height:0` | grid/flex 子项能收缩，`.scroll` 才真正滚动 |
| 自定义 `::-webkit-scrollbar` | 10px 直角滚动条（列表 / 日志 / 输出三处），hover 变深 |
| 目录列改 `shortPath()` | home 前缀换 `~`，中间省略、**保留尾部两段** —— 原来从尾部截断，`.omp` / `.qwenpaw` 被切掉，三个 dsh 分不清是哪个 preset |
| 服务端跳过「副本」目录 | 与 install.py 同一套规则；`default - 副本` 不再出现在列表里（69 行，0 条含副本） |

## 22. AstrBot 实机接入（数据根 E://data）

用户告知 AstrBot 在 E 盘，实际**数据根是 `E://data`**（不是 `E://AstrBot`）：
`cmd_config.json`、`mcp_server.json`、`plugins/`、`data_v4.db` 都在这里，
根目录只有 `astrbot.lock` 与 `.astrbot` 两个空标记文件。

两个关键事实（读文件得出，不是猜）：

| 事实 | 证据 |
|---|---|
| MCP 注册在 **`data/mcp_server.json`**，不在 `cmd_config.json` | 该文件内容就是 `{"mcpServers": {}}` |
| `cmd_config.json` 带 **UTF-8 BOM** | 直接 `json.load` 会抛 `Unexpected UTF-8 BOM`，必须 `utf-8-sig` |

已写入（均先备份）：

| 动作 | 位置 |
|---|---|
| MCP 注册 `agent_bridge` | `E://data//mcp_server.json`（备份 `mcp_server.json.agent_bridge.backup`） |
| 原生插件 | `E://data//plugins//agent_bridge//{metadata.yaml,main.py,README.md}` |

**实测**：按 `mcp_server.json` 里的原样 command/args/env 起进程 → server `neko-bridge`、
`tools/list` 返回 **8 个工具**（neko_agents / neko_dispatch / … / neko_say）。

矩阵里 `astrbot` 行改为 `verified=true / source=local`，`mcp_target` 指向真实文件。
